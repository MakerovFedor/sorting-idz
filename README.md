Описание проекта

В работе исследуются три алгоритма сортировки, реализованные на Python без использования встроенных функций сортировки.

Цель исследования — сравнить время выполнения, количество операций и потребление дополнительной памяти на массивах разных размеров и с различным расположением элементов.

Рассматриваются следующие алгоритмы:

Stupid Sort — сортировка обменами соседних элементов с возвратом к началу массива после каждого обмена.

Insertion Sort — сортировка вставками со сдвигами элементов вправо.

Quick Sort (Hoare) — быстрая сортировка с разбиением Хоара и рекурсивной обработкой полученных частей.

Для Stupid Sort используется вариант, приведённый в материалах курса ФБМФ МФТИ. Его временная сложность в худшем случае составляет O(N³). В экспериментах размер массива для этого алгоритма ограничен 500 элементами.

Зависимости проекта

Установка

Для запуска необходим Python 3 и библиотеки из requirements.txt.

В Windows откройте CMD в папке проекта и выполните:

py -m venv .venv
.venv\Scripts\activate.bat
python -m pip install -r requirements.txt

Если команда py недоступна, вместо неё можно использовать python.

Проверка корректности алгоритмов

python -m pytest -q

Запуск экспериментов

Демонстрационный запуск на небольших массивах:

python run_experiments.py

Полный эксперимент по заданным сеткам размеров:

python run_experiments.py --full --repeats 5

Результаты сохраняются в папке results/ в формате CSV и в виде графиков PNG.

Полный эксперимент может занимать значительное время, особенно на больших массивах для квадратичных и более медленных алгоритмов.

Методика исследования

Входные данные

Для каждого алгоритма рассматриваются пять типов массивов:

Случайные числа.

Уже отсортированные по возрастанию.

Отсортированные по убыванию.

Почти отсортированные, с перемешиванием приблизительно 5% позиций.

Массивы с большим количеством повторений (значения от 1 до 5).

Размеры массивов:

Алгоритм

N

100, 150, 200, 250, 300, 400, 500

Insertion Sort

Quick Sort

Для каждого сочетания алгоритма, размера и распределения выполняется несколько повторных измерений. Используются фиксированные начальные значения генератора случайных чисел (seed), что позволяет воспроизводить входные данные.

Измерение времени

Время выполнения измеряется с помощью time.perf_counter().

Создание массива и его копирование не включаются в измеряемый интервал. Проверка корректности результата выполняется после остановки таймера.

По результатам повторных запусков вычисляются:

Среднее время выполнения в миллисекундах.

Выборочное стандартное отклонение времени.

Средние количества сравнений и операций.

На графиках погрешности изображаются как среднее значение ± одно стандартное отклонение.

Подсчёт операций

Каждый алгоритм возвращает отсортированный массив и два счётчика:

(result, comparisons, operations)

comparisons — количество сравнений элементов.

operations — количество обменов для Stupid Sort и Quick Sort либо количество записей в массив для Insertion Sort.

Поскольку типы учитываемых операций различаются, их значения нельзя напрямую сравнивать между всеми алгоритмами.

Исследование памяти

Для оценки дополнительной памяти применяется модуль tracemalloc.

Измеряется пик отслеживаемых выделений памяти Python во время сортировки. Входной массив создаётся до запуска отслеживания.

Это измерение не равно общему объёму оперативной памяти, занятому процессом Python.

Jupyter Notebook

Исследовательский отчёт находится в файле ИДЗ_сортировки.ipynb.

Запуск JupyterLab:

python -m jupyter lab

После запуска необходимо открыть ноутбук и выполнить его ячейки.

По умолчанию используется демонстрационный режим (FULL_RUN = False). Для полного эксперимента необходимо установить FULL_RUN = True и выполнить расчёты повторно.

Streamlit

Для интерактивного просмотра результатов и визуализации сортировок предусмотрено приложение Streamlit.

Локальный запуск:

python -m streamlit run app.py

Приложение обычно открывается по адресу http://localhost:8501.

Для остановки приложения используйте Ctrl+C в терминале.
